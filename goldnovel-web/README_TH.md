# คู่มือเปิดเว็บ GoldNovel ฟรี (เริ่มจากศูนย์ ไม่ต้องเขียนโค้ด)

ไฟล์ในโฟลเดอร์นี้คือเว็บไซต์ **GoldNovel** ฉบับสมบูรณ์พร้อมใช้งานจริง โดยออกแบบมาให้ไม่มีรูปภาพติดมา เพื่อให้คุณอัปโหลดปกนิยาย แบนเนอร์ และป้ายโปรโมชันของคุณเองได้จากหน้า **หลังบ้านนักเขียน** โดยตรง

---

## โครงสร้างไฟล์ในโฟลเดอร์นี้
- `index.html` — ตัวเว็บไซต์ GoldNovel ครบทุกหน้า (หน้าร้าน, หน้าอ่าน, เติมเหรียญ, และหน้าหลังบ้านนักเขียน)
- `config.js` — ไฟล์ตั้งค่า 4 บรรทัดสำหรับเชื่อม Supabase และใส่เบอร์พร้อมเพย์/ทรูมันนี่ของคุณ
- `supabase_schema.sql` — สคริปต์สร้างตารางฐานข้อมูลทั้งหมดในคลิกเดียว
- `supabase_slipok_edge_function.ts` — โค้ดเสริมสำหรับเชื่อมต่อ SlipOK ตรวจสลิปอัตโนมัติ 100%
- `vercel.json` — ไฟล์ตั้งค่าสำหรับนำเว็บขึ้น Vercel

---

## ขั้นตอนที่ 1: สร้างฐานข้อมูลฟรีบน Supabase (5 นาที)
1. สมัครและล็อกอินฟรีที่ https://supabase.com/ แล้วกด **New Project** ตั้งชื่อว่า `goldnovel`
2. เมนูซ้าย กด **SQL Editor** -> **New Query**
3. เปิดไฟล์ `supabase_schema.sql` ก๊อปข้อความทั้งหมดมาวางแล้วกดปุ่ม **Run** (รอขึ้นคำว่า Success)
4. เมนูซ้าย กด **Project Settings** -> **API** แล้วคัดลอกค่า 2 ตัวนี้เก็บไว้:
   - **Project URL**
   - **anon public key**

---

## ขั้นตอนที่ 2: ใส่ค่าเชื่อมต่อใน `config.js` (1 นาที)
1. เปิดไฟล์ `config.js` ด้วย Notepad หรือ TextEdit
2. นำ **Project URL** และ **anon public key** จากขั้นตอนที่ 1 มาวางในช่อง `supabaseUrl` และ `supabaseAnonKey`
3. แก้ไขเบอร์พร้อมเพย์ ชื่อบัญชี และเบอร์ทรูมันนี่ วอลเล็ท เป็นของคุณเอง แล้วกด **Save**

---

## ขั้นตอนที่ 3: นำเว็บขึ้นออนไลน์ฟรี (GitHub + Vercel) (5 นาที)
1. สมัครบัญชีฟรีที่ https://github.com/ แล้วกด **New Repository** ตั้งชื่อ `goldnovel-web` (เลือก Private ได้)
2. กด **uploading an existing file** แล้วลากไฟล์ทั้งหมดในโฟลเดอร์นี้วางลงไป จากนั้นกด **Commit changes**
3. สมัครฟรีที่ https://vercel.com/ (ล็อกอินด้วย GitHub) -> กด **Add New Project** -> เลือก `goldnovel-web` -> กด **Deploy**
4. รอประมาณ 20 วินาที คุณจะได้ลิงก์เว็บจริง (เช่น `goldnovel-web.vercel.app`) เปิดใช้งานได้ทันทีทั้งคอมและมือถือ!

---

## ขั้นตอนที่ 4: ตั้งตัวเองเป็นเจ้าของเว็บ (Admin) เพื่ออัปโหลดปกและลงนิยาย
1. เข้าเว็บจริงของคุณ แล้วกดสมัครสมาชิกด้วยอีเมลของคุณเอง 1 ครั้ง
2. กลับไปที่ **Supabase** -> เมนูซ้าย **Table Editor** -> เลือกตาราง `profiles`
3. หาแถวอีเมลของคุณ แก้ช่อง `role` จากคำว่า `reader` เป็น **`admin`** แล้วกด Save
4. รีเฟรชหน้าเว็บ GoldNovel จะมีเมนู **"หลังบ้านนักเขียน"** ปรากฏขึ้นมาทางแถบซ้าย — กดเข้าไปอัปโหลดรูปปกนิยาย เปลี่ยนรูปแบนเนอร์ เพิ่มตอนนิยาย ตั้งราคาเหรียญ และอนุมัติสลิปได้เองทั้งหมด!

---

## ขั้นตอนที่ 5: วิธีแบ็คอัพ (สำรองข้อมูล) ให้ปลอดภัย
1. **แบ็คอัพโค้ดเว็บไซต์:** โค้ดทั้งหมดเก็บอยู่ในบัญชี GitHub ของคุณอยู่แล้ว และคุณสามารถเก็บไฟล์ `.zip` ชุดนี้ไว้ใน Google Drive ของตัวเองอีกชุดได้
2. **แบ็คอัพนิยายและข้อมูลสมาชิก (แนะนำทำเดือนละ 1 ครั้ง):**
   - เข้า **Supabase** -> **Table Editor** -> เลือกตาราง `novels`, `chapters`, `profiles`, `unlocked_chapters` แล้วกดปุ่ม **Export to CSV** เก็บไว้ใน Google Drive ของคุณ
   - นอกจากนี้ แนะนำให้เก็บต้นฉบับนิยายไว้ใน Google Docs หรือ Word ของตัวเองเสมอเป็นชุดหลักครับ
3. **ข้อควรรู้แพ็กเกจฟรี Supabase:** หากไม่มีคนเข้าเว็บเลยติดต่อกัน 7 วัน Supabase จะพักฐานข้อมูลชั่วคราว คุณแค่เข้าไปกดปุ่ม **Restore** ในหน้า Supabase ก็กลับมาใช้งานได้ฟรีเหมือนเดิมครับ
